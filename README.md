# 宵の宿 蒸 - MUSU HOTEL & RETREAT -

「自然と寝落ちする幸せ。」をコンセプトにした、架空の古民家サウナ＆安眠ホテルサイト。

## 概要
築100年の茅葺古民家を再生した里山サウナと静寂の宿。薪サウナの蒸気浴と清らかな地下天然水、土と無垢の木に包まれた客室で、心と身体がほどける体験をお届けします。

## ページ構成
- **index.html（ゆるめる）**：こだわり（客室・寝具、薪サウナと水風呂）、ロケーション、料金案内、お問い合わせフォーム
- **story.html（つながる）**：古民家再生の歴史、持続可能な取り組み、モットー、お問い合わせフォーム

## 特徴
- **上部常時表示アクション**：スクロール追従ヘッダーに「料金表」「ご予約」ボタンを常時配置
- **写真と文章の繰り返しレイアウト**：ゆったりとしたリズムと余白美を活かしたエディトリアルデザイン
- **文字と全体の動き**：1文字ずつのスプリットテキスト、写真のリビール＆視差、手描き風オーガニックボタンの呼吸するゆらぎアニメーション
